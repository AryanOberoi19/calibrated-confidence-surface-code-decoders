# qec-decoder-calibration

Calibrated confidence and certified abort thresholds for surface-code decoders, evaluated on Google's public Willow hardware data.

**Live app:** https://calibrated-qec-decoders.streamlit.app

## Status

All milestones done (M0–M6). Three confidence scores are compared: the MWPM logical gap (all 420 experiments), a belief-matching gap (112 experiments, r in 1/10/30/50) and a small learned decoder (72 experiments at d=3). Calibration and certified thresholds (RQ1, RQ2): `results/m4_summary.md`; drift, including keep-fraction transfer (RQ3): `results/m5_summary.md`; early abort learned by Q-iteration and certified by Learn-then-Test (M6, extension): `results/m6_summary.md`. The app is deployed at https://calibrated-qec-decoders.streamlit.app. 

## Quick start

```bash
python3.12 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt && pip install -e .
python scripts/check_env.py                    # environment check
python scripts/m0_threshold.py                 # M0 threshold plot -> results/
# data: download, verify and extract as in docs/data.md, then
python scripts/make_splits.py                  # rewrites splits/splits_v1.json (already committed)
python scripts/m1_baselines.py                 # PyMatching vs Google's decoders, all 420 experiments (~12 min on an M4 Pro)
python scripts/m1_summary.py                   # per-cycle error, Lambda, figures -> results/
python scripts/alpha_floor.py                  # smallest certifiable alpha -> results/
python scripts/m2_soft_outputs.py              # MWPM gap (all) and exact posterior (r=1), per-shot cache (~10 min)
python scripts/m2_summary.py                   # error vs discard and calibration on the Train split -> results/
python scripts/m2_belief_gap.py                # belief-matching gap, RL prior, r in 1/10/30/50 (~1.5 h on 10 cores)
python scripts/m3_learned.py all               # learned decoder at d=3: pretrain, fine-tune, infer (MPS, ~40 min)
python scripts/m4_calibrate_certify.py         # calibrators (Train), Learn-then-Test (Calibrate), evaluation (Test)
python scripts/m4_summary.py                   # RQ1 / RQ2 tables and figures -> results/
python scripts/m5_drift.py                     # RQ3: certify on a source, evaluate on a shifted target (~2 min)
python scripts/m5_summary.py                   # RQ3 tables and figures -> results/
python scripts/m6_prefix_gaps.py               # M6: prefix gaps for early abort, r in 10/30/50 (~2 min on 10 workers)
python scripts/m6_early_abort.py               # M6: policies (Q-iteration), Learn-then-Test, evaluation on Test
python scripts/m6_drift.py                     # M6: certified policies under shift, as in M5 (~3 min)
python scripts/m6_summary.py                   # M6 tables and figures -> results/
python scripts/build_app_data.py               # small committed data for the web app -> app/data/
streamlit run app/streamlit_app.py             # web app (deployment: docs/app.md)
python -m pytest -q
```

Details: `docs/environment.md` (setup) and `docs/data.md` (dataset).

## Layout

```
docs/          environment.md, data.md, generated data inventory
data/raw/      the extracted Zenodo archive (git-ignored)
splits/        committed split manifest (seed, shares, per-experiment checksums)
src/qeccal/    data, dem, decoders, exact, soft, calibration, guarantees, learned, sequential
scripts/       one script per figure or table; check_env, inspect_archive, m0_threshold
notebooks/     exploration only, never load-bearing
results/       committed metrics and figures
app/           Streamlit web app and its data (docs/app.md)
tests/         pytest
```

## Rules (from the spec)

- Never tune on the Test split; the score is frozen before the Calibrate split is opened.
- Every figure and table is regenerated by one script in `scripts/`.
- Every rate is reported with its shot count.
